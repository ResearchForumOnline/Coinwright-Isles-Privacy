# Coinwright Isles — Privacy and Support

Last updated: 3 October 2026

Coinwright Isles is an offline Windows game about colourful clockwork machines and restoring four miniature islands. The publisher is TalkToAI, with Shaf Games branding in the application.

## Local game information

Coinwright Isles stores your machine layouts, island construction, completed voyages, challenge progress and game preferences locally on your Windows PC. The inspected game code does not send this gameplay or these saves to the publisher. It contains no advertising service, gameplay analytics service, online multiplayer, game account, remote configuration, runtime AI service or in-game purchase service.

Coins and resources are fictional gameplay items. They have no cash value and cannot be purchased, traded or redeemed for money. The game's purchase price is handled separately by the storefront.

The game does not ask for your name, date of birth, email address, location, contacts or account credentials. Illustrations created during development are packaged as ordinary local assets; playing does not call an AI service.

## Saves, exports and deletion

Progress is kept in two local save snapshots with checksums. A checksum helps detect accidental corruption; saves are not encrypted. You may export a save or choose a save to import using the game's Windows file picker. Importing requires confirmation before replacing your current voyage. The game accesses the save file you choose, rather than scanning unrelated personal files.

The Unity build normally stores save snapshots beneath your Windows user profile at `AppData/LocalLow/Shaf Games/Coinwright Isles/CoinwrightIsles`. Installation context can affect the exact location. Uninstalling may leave saves behind. To erase progress, close the game and remove its own save folder after making any backup you want to keep. Exported saves remain wherever you chose to store them and must be removed separately if you wish to delete them.

## Microsoft Store, Windows and runtime components

Microsoft handles Store transactions, licensing, installation and platform services under its own policies. Windows and Unity runtime components may produce device or diagnostic information according to their settings and applicable terms. See the [Microsoft Privacy Statement](https://privacy.microsoft.com/privacystatement).

This notice describes the game's own gameplay and save handling. It does not claim that the whole computer or every platform component makes no network requests. Publishing this notice does not announce Store availability or certification.

## Support

For help or privacy questions, contact [shaf@talktoai.org](mailto:shaf@talktoai.org?subject=Coinwright%20Isles%20support).

Include the game version, Windows version and a short description of the issue. Send screenshots or logs only if you choose to, and remove personal information first. Do not send passwords, payment information, account tokens or unrelated personal files. Support messages are information you voluntarily send and are separate from the game's local saves. The game does not send support emails automatically.

## Ownership

This website contains only public privacy and support information. Game source code, private project files, artwork, Blender files and game binaries are not published in this repository.
